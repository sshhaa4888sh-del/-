# بَيّنة — BAYYINAH

> **لكل خطوة في حياتك، دليل.**

تطبيق جوال تفاعلي عصري باللغة العربية الكاملة (**100% Arabic RTL**) مصمم داخل إطار هاتف محمول مخصص (`390×844px` على الشاشات الكبيرة وملء الشاشة `100dvh` على الهواتف) بهوية لونية موف/بنفسجية حيوية (`#5B2C6F`، `#7D3C98`، `#F3E5F5`، `#E8DAEF`، `#F39C12`، `#FAF8FC`).

## أبرز المزايا

- **١٢ شاشة جوال متكاملة:** شاشة بداية متدرجة، ٣ شرائح تعريفية، تسجيل دخول/إنشاء حساب ومتابعة كزائر، شاشة رئيسية ببطاقة ترحيب وحلقة إنجاز دائرية، ٧ أقسام تضم ٦٣ خدمة حياتية، مخصص رحلات ذكي بالأسئلة التفاعلية، قائمة تحقق تفاعلية بلمسات احتفالية، شاشة تفاصيل إجراء شاملة مع التنقل بين الخطوات، رحلاتي، المفضلة، الإشعارات، وحسابي.
- **١٠ رحلات سعودية رئيسية عميقة وواقعية** تشمل افتتاح محل تجاري، فتح متجر إلكتروني، شراء منزل، استئجار منزل، الزواج وتوثيق العقد، تسجيل المواليد، شراء سيارة مستعملة ونقل ملكيتها، الاستقالة والمستحقات، إجراءات الوفاة وحصر الورثة (بلغة هادئة ومحترمة)، والتعرض للاحتيال المالي والشكاوى التجارية — مع روابط للمنصات السعودية الرسمية الموثقة فقط (`business.sa`, `balady.gov.sa`, `absher.sa`, `najiz.sa`, `qiwa.sa`, `ejar.sa`, `zatca.gov.sa`, `gosi.gov.sa`, `splonline.com.sa`, `seha.sa`, `mc.gov.sa`).
- **محرك بحث عربي ذكي** يدعم تطبيع الحروف والتعبيرات السعودية اليومية.
- **حفظ تلقائي ومستمر في `localStorage`** لبيانات المستخدم، الرحلات، الخطوات المكتملة، المفضلة، والإشعارات.

## التشغيل المحلي

```bash
npm install
npm run dev      # التشغيل على http://127.0.0.1:5173
npm run build    # التحقق من الأنواع وبناء نسخة الإنتاج
```

## إخلاء مسؤولية قانوني

> بَيّنة منصة إرشادية مستقلة تهدف إلى تسهيل الوصول إلى المعلومات والإجراءات، ولا تمثل أي جهة حكومية. المعلومات المقدمة للتوعية والإرشاد ويُنصح بالرجوع للمنصة الرسمية المختصة للتحقق من آخر التحديثات.
